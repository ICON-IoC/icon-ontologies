ICON Data ontology

Data resources at three levels (dataset, database, data repository): who creates, publishes, hosts, funds and uses them, what they cover in time, space and subject, and how they derive from and hold one another.

TermKindIDDefinition
data resource class ICON:0008000 Data at any of three levels: a dataset, a database or a data repository. Replaced the PPOD Dataset class.
dataset class ICON:0008001 One collection of data published as a unit by its creator, such as a map layer, a table or a time series. Example: Cropland Data Layer.
database class ICON:0008002 A maintained collection of related datasets kept together under one design, usually by one organization and usually queryable. Its datasets are part of it. Example: California Natural Diversity Database.
data repository class ICON:0008003 A platform that holds and publishes datasets and databases, often from many creators. Example: CDFW BIOS.
data type class ICON:0008080 The kind of data, or the form it comes in. One list holds both, so a Data record and a tool's input or output are described in the same terms and a dataset can be matched to the tools that take it: Land cover or vegetation map and Raster describe both the Cropland Data Layer and an input InVEST takes.
data format class ICON:0008010 The form data comes in, from the Terms sheet's dataset types; formats are data types, listed with the kinds of data (#304). DCAT records format on each downloadable distribution; the graph keeps it on the data until a resource has more than one form worth recording.
data access level class ICON:0008020 Who can get the data. The Dataset Dictionary's Availability. Each value maps to the EU access-right list and to the DCAT-US access levels data.gov uses.
temporal resolution value class ICON:0008030 How far apart in time the data's values are. Each value carries, as a cross-reference, the ISO 8601 duration that dcat:temporalResolution takes on export.
social unit class ICON:0008040 A unit of people or property that social data is recorded for. The analysis unit of DDI Discovery.
has data level relation ICON:0008100 Links a data resource to the level class it belongs to: dataset, database or data repository. The explorer's way of stating its class, so it can filter and colour by level.
is data level of relation ICON:0008101 The reverse of has data level.
has data type relation ICON:0008102 A kind of data the record is, or the form it comes in, from the Data type list.
is data type of relation ICON:0008103 The reverse of has data type.
is held in relation ICON:0008104 A dataset, database or smaller repository is held and published by a repository. One resource can be held in several.
holds relation ICON:0008105 The reverse of is held in.
is hosted by relation ICON:0008106 The organization that runs the systems the data is served from. The Dataset Dictionary's Host role.
hosts relation ICON:0008107 The reverse of is hosted by.
is derived from relation ICON:0008108 Data built from other data, such as a connectivity map made from land cover and roads.
is source of relation ICON:0008109 The reverse of is derived from.
conforms to relation ICON:0008110 A standard or guideline a data resource, tool, plan or plan action follows, recorded as a guideline: a data standard such as Darwin Core or the FGDC metadata standard, the policy whose required analyses a tool carries out, the agency guide a plan was written to, or the guidelines an action says to follow.
is followed by relation ICON:0008111 The reverse of conforms to.
has extent relation ICON:0008112 A place whose boundary is the data's extent, such as a watershed or a preserve.
is extent of relation ICON:0008113 The reverse of has extent.
collected at relation ICON:0008114 A place where the data was gathered, such as a monitoring station.
is collection site of relation ICON:0008115 The reverse of collected at.
social resolution relation ICON:0008204 The smallest social unit the data describes or can be broken down to, such as household or census tract.
purpose attribute ICON:0008200 Why the data was made.
coverage start attribute ICON:0008201 The first year the data describes. With coverage end, the Dataset Dictionary's Time Period; exported as dcterms:temporal with a dcat:startDate.
coverage end attribute ICON:0008202 The last year the data describes; blank while it is still being added to.
spatial resolution attribute ICON:0008203 Grid cell size, mapping unit or positional accuracy, written with its unit: 30 m for C-CAP, 4 km for gridMET. Converted to dcat:spatialResolutionInMeters on export when the unit is a length.
Identifier attribute dcterms:identifier A DOI or the repository's own accession number.
version attribute dcat:version The version indicator (name or identifier) of a resource.
Accrual Periodicity attribute dcterms:accrualPeriodicity How often the data is updated, as a value of the EU frequency list above.
temporal resolution attribute dcat:temporalResolution minimum time period resolvable in a dataset.
keyword attribute dcat:keyword A keyword or tag describing a resource.
observation records value ICON:0008081 Individual sightings or detections of a species or feature, each with a place and a date, such as CNDDB occurrences or camera trap detections.
survey and monitoring data value ICON:0008082 Measurements taken by a protocol across sites or over time: counts, plots, catch, water samples.
species range or distribution value ICON:0008083 Where a species lives or is known to occur, mapped as a range or distribution.
habitat suitability model value ICON:0008084 Modelled predictions of where habitat is suitable for a species or community.
land cover or vegetation map value ICON:0008085 A map of what covers the land: vegetation types, crops, forest structure, developed and bare ground.
satellite and aerial imagery value ICON:0008086 Images of the ground taken from satellites, aircraft or drones, and products derived directly from them.
elevation model value ICON:0008087 A surface of ground elevation, slope or water depth (bathymetry).
climate grids and projections value ICON:0008088 Gridded climate variables, observed or projected, such as temperature, precipitation or evapotranspiration.
stream and water network value ICON:0008089 Mapped streams, rivers, lakes, wetlands and the barriers, diversions and conveyances on them.
sensor time series value ICON:0008090 Readings over time from gauges, weather stations or other sensors.
boundaries and areas value ICON:0008091 Administrative, planning, regulatory and survey boundaries, and the areas a user draws or picks.
parcels and ownership value ICON:0008092 Land parcels and records of who owns or holds rights in them, such as easements.
infrastructure locations value ICON:0008093 Mapped locations of built structures and facilities: roads, ports, crossings, stations, platforms.
scenarios and settings value ICON:0008094 Choices a user enters: practices, targets, parameters, costs, management or development scenarios.
estimates and indices value ICON:0008095 Computed values: estimates of carbon, cost or yield, and scores, ranks or indices that compare places or options.
project records value ICON:0008096 Records of conservation projects: where they are, what they do, their funding and status.
funding opportunities value ICON:0008097 Listings of grants, loans and other funding that people can apply for: the funder, what it pays for, award size and deadline.
image data format value ICON:0008011 Photographs or scanned images.
raster data format value ICON:0008012 A grid of cells, each with a value, such as a land cover map or a climate surface.
shapefile data format value ICON:0008013 Points, lines or polygons with attributes, in the Esri shapefile or a similar vector format.
tabular data format value ICON:0008014 Rows and columns, as a spreadsheet or a database table.
map data format value ICON:0008015 A finished map, interactive on the web or printed, made for people to read rather than as data to analyse. Mostly a tool's output.
report data format value ICON:0008016 A written document, such as a PDF report or a site summary. Mostly a tool's output.
open data access value ICON:0008021 Anyone can download the data without signing in.
open access with registration value ICON:0008022 The data is free after creating an account or accepting terms.
sensitive locations withheld value ICON:0008023 The data is published with sensitive detail, such as rare species locations, generalized or held back unless a request is approved.
access by request or license value ICON:0008024 The data is available only through an agreement, a subscription or a fee.
data not public value ICON:0008025 The data is held for its creator's own use.
hourly resolution value ICON:0008031 A value every hour.
daily resolution value ICON:0008032 A value every day.
weekly resolution value ICON:0008033 A value every week.
monthly resolution value ICON:0008034 A value every month.
annual resolution value ICON:0008035 A value every year.
multi-year resolution value ICON:0008036 Values for periods longer than a year, such as decades.
single snapshot value ICON:0008037 One point or period in time.
continuous value freq:CONT The item is updated more frequent than daily.
daily value freq:DAILY The event occurs once a day.
weekly value freq:WEEKLY The event occurs once a week.
monthly value freq:MONTHLY The event occurs once a month.
quarterly value freq:QUARTERLY The event occurs every three months.
annual value freq:ANNUAL The event occurs once a year.
biennial value freq:BIENNIAL The event occurs every two years.
quinquennial value freq:QUINQUENNIAL The event occurs every five years.
irregular value freq:IRREG The event occurs at uneven intervals.
never value freq:NEVER The item is never updated.
individual person unit value ICON:0008041 Data recorded person by person.
household unit value ICON:0008042 Data recorded household by household.
parcel or landowner unit value ICON:0008043 Data recorded by land parcel or landowner.
organization unit value ICON:0008044 Data recorded organization by organization.
census block group unit value ICON:0008045 Data recorded by Census block group.
census tract unit value ICON:0008046 Data recorded by Census tract.
city or town unit value ICON:0008047 Data recorded by city or town.
county unit value ICON:0008048 Data recorded by county.
