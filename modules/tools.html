ICON Tools ontology

Software people use to plan, assess and track conservation work: decision-support tools, map viewers, dashboards, calculators and models, and software packages. Covers who builds and uses them, the issues they address, and the data they take in and produce.

TermKindIDDefinition
tool class ICON:0013000 Software people use to plan, assess or track conservation work: a decision-support tool, a map viewer, a dashboard, a calculator or model, a software package or an identification key. A site whose main job is holding and serving data is a data repository, not a tool; a tool that works with such data links to it. Read from the master PPOD workbook's Tools sheet.
decision-support tool class ICON:0013001 A tool that helps choose where or how to act: it ranks or prioritizes sites, compares scenarios, or screens a proposal against conservation values. Example: Ecosystem Management Decision Support System.
map viewer class ICON:0013002 A web application for browsing and querying map layers. Example: Wetlands Mapper.
dashboard class ICON:0013003 A web page that tracks a set of indicators in charts and maps, often over time. Example: California Carbon Dashboard.
calculator or model class ICON:0013004 A tool that computes an estimate from its user's inputs or runs a model, such as the carbon a riparian planting stores or the habitat a site provides. Example: Carbon in Riparian Ecosystems Estimator for California.
software package class ICON:0013006 Software its users install and run themselves, such as an R package, a desktop program or a trained model, rather than use on the web. Example: InVEST.
identification key class ICON:0013007 A guide that leads its user, step by step or by comparing pictures, to the name of a plant or animal they have found. Example: Berkeley BioKeys.
tool function class ICON:0013010 What a tool does for its user, such as prioritizing places or estimating carbon. A tool can have several.
has tool type relation ICON:0013100 Links a tool to a kind of tool it is. A tool can be of several kinds, as a map viewer that also prioritizes sites.
is tool type of relation ICON:0013101 The reverse of has tool type.
produces relation ICON:0013102 The tool creates or serves this data: the layers a map viewer publishes, the estimates a calculator outputs. The workbook's outDataset column.
is produced by relation ICON:0013103 The reverse of produces.
has tool function relation ICON:0013104 Links a tool to something it does for its user.
is tool function of relation ICON:0013105 The reverse of has tool function.
takes input relation ICON:0013106 A kind of data, or a format, the tool takes in, from the Data type list that also describes Data records, so data can be matched to the tools that take it. A specific Data record the tool uses is a uses data from link instead.
is input to relation ICON:0013107 The reverse of takes input.
gives output relation ICON:0013108 A kind of data, or a format, the tool gives back, from the Data type list. A specific Data record the tool creates is a produces link instead.
is output from relation ICON:0013109 The reverse of gives output.
prioritizing function value ICON:0013011 Ranks or scores places, sites or projects so the best ones can be chosen first.
screening function value ICON:0013012 Checks a proposed project against rules, sensitive resources or eligibility criteria before it goes ahead.
carbon estimating function value ICON:0013013 Calculates carbon stored or greenhouse gases emitted or avoided.
projecting function value ICON:0013014 Shows how conditions may change under future climate, sea level rise or land use.
habitat quantifying function value ICON:0013015 Measures how much habitat there is and how good it is.
mapping function value ICON:0013016 Shows where resources, conditions or hazards are, for browsing and querying.
vulnerability assessing function value ICON:0013017 Judges how exposed and sensitive people, places or species are to a threat.
scenario comparing function value ICON:0013018 Runs alternative management or development choices side by side to weigh their effects.
recommending function value ICON:0013019 Suggests what to do or plant, such as fertilizer rates, seedlots or meadow species.
tracking function value ICON:0013020 Records projects, prices or indicators over time and reports on them.
species detecting function value ICON:0013021 Finds and counts animals or plants, as in images.
funding application function value ICON:0013022 Helps applicants build a proposal or meet the requirements of a grant program.
